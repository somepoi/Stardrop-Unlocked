# Stardrop Unlocked

Stardrop Unlocked is a modified fork of [Floogen/Stardrop](https://github.com/Floogen/Stardrop), an open-source, cross-platform mod manager for the game [Stardew Valley](https://www.stardewvalley.net/). The modification removes client-side UI checks for Nexus Premium and adds a browser-based fallback that lets free-tier Nexus Mods users download mods through Stardrop using the existing [NXM link flow](https://github.com/Nexus-Mods/node-nexus-api/blob/master/docs/classes/_nexus_.nexus.md).

Stardrop is built using the Avalonia UI framework. It utilizes [SMAPI (Stardew Modding API)](https://smapi.io/) to simplify the management and update checking for all applicable Stardew Valley mods.

Profiles are also supported, allowing users to have multiple mod groups for specific gameplay or multiplayer sessions.
